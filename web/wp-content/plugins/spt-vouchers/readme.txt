Gestion securisee des vouchers prepayes SPT pour WooCommerce.

== Description ==

Import manuel des six produits, chiffrement, stocks, attribution transactionnelle et envoi des vouchers par email.
Les notifications contenant les codes ne sont pas actives dans la version 0.2.0.

== Installation ==

1. Definir SPT_VOUCHERS_ENCRYPTION_KEY dans wp-config.php.
2. Installer et activer l archive depuis WordPress.
3. Importer les fichiers dans Vouchers SPT > Importer.
4. Laisser l attribution automatique desactivee jusqu a la fin des tests de paiement.
